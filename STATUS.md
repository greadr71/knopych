## Ограничения

- **Обновить мост из самого приложения нельзя** — whitelist GWM в `PackageInstaller`.
  Только adb.
- **adb по Wi-Fi** включается вручную, из приложения нельзя (SELinux).
- **Светодиоды 1–3 не припаяны**: активный слот памяти сиденья на панели не виден,
  кнопки при этом работают.
- **Датчика освещённости в машине нет**: «темно ли» определяется по решению автосвета,
  поэтому автояркость работает по времени и гистерезису, а не по люксу.
- **Только ГУ на test-keys**: на обычной прошивке мост не получит системных прав.
- **Прошивка панели не обновляется по воздуху** — только USB.
