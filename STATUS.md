## Ограничения

Мост ставится только через adb: GWM держит whitelist в `PackageInstaller`, из самого
приложения пакет не обновишь. adb по Wi-Fi тоже включается вручную, из приложения его
не поднять (SELinux).

Светодиоды 1–3 не припаяны, поэтому активный слот памяти сиденья на панели не виден.
Кнопки при этом работают.

Датчика освещённости в машине нет. «Темно ли» мост решает по автосвету, так что
автояркость работает по времени и гистерезису, без люксов.

Нужно ГУ на test-keys: на обычной прошивке мост не получит системных прав. Прошивка
панели обновляется только по USB, по воздуху она не умеет.
