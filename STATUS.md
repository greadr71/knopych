## Осталось

- **Стоянка** на живой машине: `tools/kn.py park` до и после заводки, после короткой
  остановки сценарий подогрева должен пропускаться.
- **Лобовое с заведённым двигателем** и автозапуск.
- **Ближний свет**: своего свойства в HAL нет — нужен ли отдельный признак, решится по месту.

## Ограничения

Мост **обновляется** только через adb: GWM держит whitelist в `PackageInstaller`, из
самого приложения пакет не обновишь. Первичная установка — с флешки FAT32 через файловый
менеджер ГУ (USB в режиме `host`). adb по Wi-Fi включается вручную, один раз с компьютера
по кабелю (`adb root`, `setprop persist.adb.tcp.port 5555`), из приложения его не поднять
(SELinux).

Светодиоды кнопок прошивка v1.0 не зажигает: какой слот памяти сиденья активен,
показывает плашка на экране ГУ. Кнопки работают как обычно.

Датчика освещённости в машине нет. «Темно ли» мост решает по автосвету, так что
автояркость работает по времени и гистерезису, без люксов.

Нужно ГУ на test-keys: на обычной прошивке мост не получит системных прав. Прошивка
панели обновляется только по USB, по воздуху она не умеет.
