# Словарь терминов

- **CAN-шина** — «общий чат» блоков машины. Пара проводов, по которой все электронные блоки (климат, сиденья, двигатель, экран) обмениваются короткими сообщениями. Нажатие на экране = экран отправляет в шину сообщение «включи подогрев», блок сидений его выполняет.
- **CAN-H / CAN-L** — два провода одной шины (high / low). Сигнал передаётся разницей напряжений между ними. Всегда идут парой, часто перекручены.
- **CAN ID** — «тема» сообщения: число, по которому блоки понимают, что это за сообщение (например, «климат»). Внутри — до 8 байт данных (что именно включить).
- **CAN-FD** — более новая и быстрая версия CAN (до 64 байт в сообщении). Не всё железо её понимает.
- **OBD / OBD-II** — диагностический разъём под рулём. Туда вставляют ELM327 и сканеры. На Haval к нему выведена только диагностическая шина.
- **Шлюз (gateway)** — блок-«охранник» между шинами. Пропускает в OBD только диагностику, а внутренний «чат» блоков туда не транслирует.
- **BCM (Body Control Module)** — блок управления кузовом: свет, замки, обогревы. Подключен к шине комфорта.
- **ГУ (головное устройство)** — магнитола/планшет с экраном. На Dargo это Android-подобная система.
- **Снифинг (sniffing)** — подслушивание шины: записываем все сообщения, нажимаем кнопку на экране и смотрим, какое сообщение появилось.
- **CAN-адаптер / CANable** — USB-флешка, которая подключает ноутбук к CAN-шине для снифинга.
- **SavvyCAN** — бесплатная программа для записи и сравнения логов CAN.
- **ELM327** — дешёвый OBD-адаптер для чтения ошибок. Медленный, для снифинга не годится.
- **Микроконтроллер (ESP32, Arduino)** — маленький компьютер на плате, «мозг» устройства с кнопками.
- **ESP32** — микроконтроллер со встроенными CAN, Wi-Fi и Bluetooth. Стоит 300–600 ₽.
- **Трансивер (SN65HVD230 и др.)** — микросхема-«переводчик» между микроконтроллером и проводами CAN. Нужна обязательно.
- **Параллельное подключение** — подключаемся к проводам, не разрезая их, как ответвление.
- **Переходник «папа-мама» (T-harness)** — вставляется между штатным разъёмом и блоком, даёт ответвление проводов. Снимается без следов.
- **ACC** — питание, которое есть только при включённом зажигании. Нужно, чтобы устройство не сажало аккумулятор на стоянке.
- **UDS** — язык диагностических команд. Через него сканеры читают ошибки и иногда «дёргают» исполнительные устройства (например, включают реле для теста).
- **APK / ADB** — APK это установочный файл Android-приложения, ADB — способ поставить его на устройство с компьютера.
- **BLE** — Bluetooth Low Energy, экономичный Bluetooth. Кнопка на батарейке-таблетке живёт на нём 1–2 года.
