# Распиновка v1 — макетка (архив)

Первая сборка на беспаечной макетке (MB-102), ESP подключена проводами «мама-папа»
(на ESP впаяны штыревые разъёмы, на макетку она не ставится). Версия заморожена, повторять не нужно:
плата и общая электрика — [../../docs/hardware.md](../../docs/hardware.md).
Прошивка — [../firmware/knopych-panel/knopych-panel.ino](../firmware/knopych-panel/knopych-panel.ino) (v0.6).

## Кнопки и светодиоды
| № | Кнопка (GPIO) | Светодиод (GPIO) |
|---|---|---|
| 1 | 1 | 8 |
| 2 | 2 | 9 |
| 3 | 4 | 10 |
| 4 | 5 | 11 |
| 5 | 6 | 12 |
| 6 | 7 | 44 (припаян на RX) |

Левая сторона Zero сверху вниз: `5V, GND, 3V3, 1, 2, 3, 4, 5, 6`. Правая: `43(TX), 44(RX), 13, 12, 11, 10, 9, 8, 7`.
44 подписан RX: UART0 не используем, журнал идёт через USB CDC. Свободны были 13 и 43 — их занял энкодер
(в v2 он уже на 9 и 10, см. [../../v2/docs/pins.md](../../v2/docs/pins.md)).

На макетке стояли тактовые 12×12 KLS7-TS1204-7.3-180 (SWT-9) — в печатный корпус они не идут,
там MX-совместимые свитчи.

## Схема
- **Свитч:** GPIO → ножка, вторая ножка → GND, внутренняя подтяжка `INPUT_PULLUP`, нажата = `LOW`.
- **Светодиод:** GPIO → резистор 330 Ом → анод (длинная нога), катод → GND. Горит при `HIGH`.
- **Общий GND:** на плате один земляной контакт → все 12 нагрузок в одну точку («звезда»).

## Базовый тестовый скетч (Arduino)
```cpp
const int BTN[6] = {1, 2, 4, 5, 6, 7};
const int LED[6] = {8, 9, 10, 11, 12, 44};  // 6-й на RX: UART0 не используется
bool on[6], wasPressed[6];

void setup() {
  for (int i = 0; i < 6; i++) { pinMode(BTN[i], INPUT_PULLUP); pinMode(LED[i], OUTPUT); }
}

void loop() {
  for (int i = 0; i < 6; i++) {
    bool pressed = digitalRead(BTN[i]) == LOW;
    if (pressed && !wasPressed[i]) { on[i] = !on[i]; digitalWrite(LED[i], on[i]); }
    wasPressed[i] = pressed;
  }
  delay(20);
}
```

## Историческое: как выбирали связь
- **BLE, в запасе USB.** Первый прототип жил только по USB: на старой плате (клон DevKitC-1
  YD-ESP32-S3) включение радио роняло питание (BROWNOUT) — скетч `radio-test` в публичную копию
  не вошёл. На Zero радио работает, и мост на ГУ подключается к панели по BLE.
- Рассматривали два варианта на стороне ГУ: **BLE HID-клавиатура** (MacroDroid на ГУ ловит нажатия;
  не проверено, пустит ли стек Aptiv) и **свой GATT-сервис** (выбрали его; переход на новую плату —
  в истории проекта).
